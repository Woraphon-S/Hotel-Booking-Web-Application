# ระบบจองที่พักออนไลน์

เว็บแอปพลิเคชันจองที่พักออนไลน์ที่ให้ผู้ใช้ค้นหา เปรียบเทียบ และจองห้องพักได้ครบในที่เดียว พร้อมระบบสำหรับเจ้าของที่พักในการลงประกาศและดูแลห้องพักของตนเอง ใช้งานเป็นภาษาไทยทั้งหมด และวางกฎการทำงานเบื้องหลังให้รัดกุมเหมือนเว็บจองที่พักจริง

## ภาพรวม

ระบบรองรับผู้ใช้สองกลุ่มหลัก คือ ผู้เข้าพักที่เข้ามาค้นหาและจองที่พัก และเจ้าของที่พักที่นำที่พักมาเปิดให้จอง ผู้ใช้เปิดดูและค้นหาที่พักได้ทันทีโดยไม่ต้องเข้าสู่ระบบ และจะเข้าสู่ระบบเมื่อต้องการจอง รีวิว ชำระเงิน หรือลงประกาศที่พักเท่านั้น

## ฟีเจอร์หลัก

**ค้นหาและเปรียบเทียบที่พัก**
ค้นหาที่พักตามชื่อหรือจังหวัด กรองตามช่วงราคา จัดเรียงผลลัพธ์ และสลับดูได้ทั้งแบบรายการและแบบแผนที่ เพื่อเลือกที่พักที่ใช่ที่สุด

**จองห้องพัก**
เลือกห้อง เลือกวันเข้าพักและวันออก ระบบคำนวณจำนวนคืนและราคารวมให้อัตโนมัติ พร้อมตรวจสอบห้องว่างก่อนยืนยันทุกครั้ง

**ชำระเงินและยืนยันการจอง**
ชำระเงินเพื่อยืนยันการจอง และติดตามสถานะของแต่ละการจองได้จากหน้าโปรไฟล์

**รีวิวจากผู้เข้าพักจริง**
ผู้ที่เคยจองและเข้าพักแล้วให้คะแนนและเขียนรีวิวได้ และเจ้าของที่พักตอบกลับรีวิวได้

**ระบบสำหรับเจ้าของที่พัก**
ลงประกาศที่พัก อัปโหลดรูปภาพ เลือกสิ่งอำนวยความสะดวก และจัดการห้องพักกับราคาผ่านแผงควบคุมของตนเอง

## จุดเด่นด้านการทำงานของระบบ

สิ่งที่ทำให้ระบบนี้ทำงานได้อย่างน่าเชื่อถือ คือกฎเบื้องหลังที่ดูแลความถูกต้องของข้อมูลให้โดยอัตโนมัติ

**ป้องกันการจองซ้ำ**
ก่อนสร้างการจองทุกครั้ง ระบบตรวจสอบว่าห้องยังว่างในช่วงวันที่เลือก และจัดการคำขอที่เข้ามาพร้อมกันอย่างปลอดภัย เพื่อไม่ให้ห้องเดียวกันถูกจองเกินจำนวนที่มีอยู่จริง

**รีวิวที่เชื่อถือได้**
อนุญาตให้รีวิวได้เฉพาะที่พักที่ผู้ใช้เคยจองและยืนยันการจองแล้วเท่านั้น ทำให้คะแนนและรีวิวมาจากประสบการณ์จริง ไม่ใช่รีวิวปลอม

**ราคาที่คำนวณจากฝั่งระบบ**
ราคารวมคิดจากราคาห้องจริงและจำนวนคืนที่เข้าพักโดยระบบเป็นผู้คำนวณเอง ไม่อิงตัวเลขที่ส่งมาจากฝั่งผู้ใช้ จึงมั่นใจได้ว่ายอดเงินถูกต้องเสมอ

**ขอบเขตสิทธิ์ตามบทบาท**
ผู้ใช้แต่ละคนเข้าถึงและจัดการได้เฉพาะข้อมูลของตนเอง เจ้าของที่พักแก้ไขได้เฉพาะที่พักของตน และผู้เข้าพักดูได้เฉพาะการจองของตน

**สถานะการจองที่ชัดเจน**
แต่ละการจองมีสถานะกำกับตั้งแต่รอชำระเงิน ยืนยันแล้ว เข้าพักแล้ว ไปจนถึงยกเลิก ทำให้ทั้งผู้เข้าพักและเจ้าของที่พักติดตามได้ง่าย

## ฟีเจอร์ย่อยที่ใส่ใจรายละเอียด

- มุมมองแผนที่แสดงตำแหน่งที่พักประกอบการตัดสินใจ
- แกลเลอรีรูปภาพที่กดขยายดูเต็มจอได้
- คำนวณจำนวนคืนและราคารวมให้อัตโนมัติขณะเลือกวันที่
- บันทึกที่พักที่ชอบไว้ในรายการโปรดเพื่อกลับมาดูภายหลัง
- เจ้าของที่พักตอบกลับรีวิวของผู้เข้าพักได้โดยตรงใต้รีวิว
- สลับการแสดงผลภาษาไทยและภาษาอังกฤษได้
- คงสถานะการเข้าสู่ระบบไว้ และพากลับมายังหน้าที่กำลังทำอยู่หลังเข้าสู่ระบบ

## เทคโนโลยีที่ใช้โดยย่อ

ส่วนหน้าเว็บพัฒนาด้วย Next.js และ React ส่วนระบบหลังบ้านพัฒนาด้วย NestJS และใช้ฐานข้อมูล PostgreSQL

## การติดตั้งและเริ่มใช้งาน

ต้องมี Node.js และ Docker ติดตั้งในเครื่องก่อน จากนั้นทำตามขั้นตอนนี้

1. เริ่มฐานข้อมูล

   docker compose up -d db

2. เริ่มฝั่งเซิร์ฟเวอร์ ที่โฟลเดอร์ server

   npm install
   npm run start:dev

3. เริ่มฝั่งหน้าเว็บ ที่โฟลเดอร์ client

   npm install
   npm run dev

เมื่อรันครบทั้งสามส่วนแล้ว เปิดใช้งานเว็บได้ที่ http://localhost:3000
